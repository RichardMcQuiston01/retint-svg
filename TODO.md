## Bulk Image Converter

Convert one or more images to various image formats directly from the Shell Extension(aka Context) menu. Users can define settings for various image formats, which are used when converting them images.

- Example: <https://www.xnview.com/en/xnconvert/>

## Batch Image Resizer

Resize one or more images to various sizes directly from the Shell Extension(aka Context) menu. There are a set of default size settings(25%, 50%, 200%, etc.), but users can also customize the options with their own custom sizes or percentages.

- Example: <https://www.xnview.com/en/xnresize/>
